Compatibility

Supported page patterns

  • Native HTML table rows.
  • ARIA grid and treegrid rows.
  • Common interactive list items.
  • Visible buttons, links, menu items, and common custom button controls.
  • Action names exposed through visible text, accessible labels, linked ARIA references, tooltip attributes, SVG titles, icon classes, and data attributes.
  • Common menu, dropdown, popover, and context-menu containers.

GitHub branches

The GitHub adapter targets repository branch listing pages. It excludes main, master, gh-pages, and rows marked default or protected. It looks for a clear Delete/Remove action and checks that the branch disappears from the listing.

Known limitations

  • Canvas-rendered controls are not discoverable through normal DOM inspection.
  • Closed shadow roots hide their internal controls.
  • Unlabeled controls with no useful metadata cannot be safely classified.
  • Hover-only menus may not be discovered.
  • Highly virtualized lists may only expose a subset of rows.
  • Some confirmation dialogs may need manual handling.

When an action cannot be identified with confidence, BulkOperation stops rather than guessing.
