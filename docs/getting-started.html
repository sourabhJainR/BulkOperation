Getting started

Requirements

Google Chrome or a compatible Chromium-based browser and a downloaded BulkOperation release ZIP.

Install

  1. Open the Releases page.
  2. Download BulkOperation-Installer.zip from a published release.
  3. Extract the ZIP.
  4. Open chrome://extensions.
  5. Enable Developer mode.
  6. Select Load unpacked.
  7. Choose the extracted BulkOperation/extension folder.

The Windows helper opens the extensions page and prints the folder path. It does not install the extension automatically.

Run a bulk action

  1. Open a supported page.
  2. Click the BulkOperation toolbar icon.
  3. Select Enable selection on this page.
  4. Select the target rows.
  5. Choose an action from the bulk toolbar.
  6. Review the target list and confirm.
  7. Review the per-item results.

Important

Start with a small test selection. A third-party page can change its controls or navigate away while an operation is running.
