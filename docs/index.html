Handle repetitive row actions with care.

BulkOperation adds multi-row selection to supported webpage tables, grids, and lists, then runs a compatible visible action on each item in sequence.

Download a releaseInstallation guide

What it does

Select multiple rows

Adds selection controls to supported tables, grids, and interactive lists.

Find visible actions

Uses labels, accessible names, tooltip metadata, icons, and common menus to find row actions.

Run one at a time

Processes selected items sequentially and reports each result.

Fail safely

Requires review before destructive actions and avoids guessing when controls are unclear.

Designed with safety in mind

BulkOperation interacts with visible page controls. It does not use hidden site APIs, bypass permissions, or send page content to a BulkOperation server. Protected and default GitHub branches are excluded by the GitHub adapter.

DOM-based automation has limits. Some custom controls, closed shadow roots, canvas interfaces, hover-only menus, and virtualized grids may not be supported.
