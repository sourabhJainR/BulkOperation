Release asset

Look for BulkOperation-Installer.zip under the release you want to install.

Installation

  1. Extract the downloaded ZIP.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and choose BulkOperation/extension.

See the getting started guide for details.
