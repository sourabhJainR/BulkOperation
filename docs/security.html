Security

Safety model

  • Interact with visible page controls only.
  • Do not call private website APIs or bypass access controls.
  • Require explicit review and confirmation before a bulk action.
  • Process items sequentially and report per-item failures.
  • Fail closed when an action cannot be identified with sufficient confidence.
  • Exclude protected and default branches in the GitHub adapter.

Report a vulnerability

Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the repository maintainer through a trusted private channel. Do not include passwords, cookies, access tokens, session identifiers, or private customer data.
