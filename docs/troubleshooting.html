Troubleshooting

The popup cannot reach the page

  1. Confirm the extension is enabled in chrome://extensions.
  2. Refresh the webpage.
  3. Open the popup and enable selection again.
  4. Check that the page is not a Chrome internal or restricted browser page.

No row checkboxes appear

The page may not use a supported table, ARIA grid, or list structure. Highly virtualized and custom-rendered pages may require a site adapter.

An action is missing

Check whether the row exposes a visible label, accessible name, tooltip, icon metadata, or discoverable menu trigger. Unlabeled controls are intentionally not guessed.

An operation reports failures

The page may have changed, navigated away, opened an unsupported confirmation dialog, or removed a control. Review the result list before retrying.

Report reproducible problems through GitHub Issues. Remove private data and credentials before sharing logs or screenshots.
