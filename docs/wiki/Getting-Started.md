# Getting started

1. Download `BulkOperation-Installer.zip` from [GitHub Releases](https://github.com/sourabhJainR/BulkOperation/releases).
2. Extract the ZIP.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose `BulkOperation/extension`.

To run a bulk action, open a supported page, click the extension icon, enable selection, select rows, choose an action, review the target list, and confirm.

The Windows helper opens the extension management page and prints the folder path. It does not install the extension automatically.
