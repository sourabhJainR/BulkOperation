# Publishing the GitHub Wiki

The repository has GitHub Wiki support enabled. GitHub does not create the separate Wiki repository until its first page is initialized.

1. Open https://github.com/sourabhJainR/BulkOperation/wiki.
2. Select **Create the first page**.
3. Create the page named **Home**.
4. Copy the matching Markdown content from `docs/wiki/Home.md`.
5. Create the remaining pages using the matching files in `docs/wiki/`.

The repository keeps the source copies under version control so Wiki changes can be reviewed and updated with the code. Keep the website documentation under `docs/` in sync with important user-facing Wiki changes.
