# Publishing the GitHub Wiki

The GitHub Wiki Home page has already been created. Do not create another Home page.

The remaining Wiki pages are maintained as Markdown source files in `docs/wiki/`. Publish them to the existing Wiki as follows:

1. Open the [BulkOperation Wiki](https://github.com/sourabhJainR/BulkOperation/wiki).
2. Use **New Page** to create each page listed below. Keep the page title and URL slug aligned with the source filename.
3. Copy the matching Markdown content from the source file into the Wiki editor and save the page.
4. Return to the Wiki Home page and confirm that each link opens the published page.

| Wiki page | Source file |
|---|---|
| Getting Started | `docs/wiki/Getting-Started.md` |
| How Bulk Actions Work | `docs/wiki/How-Bulk-Actions-Work.md` |
| Compatibility | `docs/wiki/Compatibility.md` |
| Safety and Privacy | `docs/wiki/Safety-and-Privacy.md` |
| Troubleshooting | `docs/wiki/Troubleshooting.md` |
| Releases | `docs/wiki/Releases.md` |
| Contributing | `docs/wiki/Contributing.md` |

Keep the source copies under version control so Wiki changes can be reviewed and updated with the code. Keep the website documentation under `docs/` in sync with important user-facing Wiki changes.
