# Safety and privacy

- Actions use visible page controls.
- Destructive actions require review and confirmation.
- Items are processed sequentially.
- Per-item failures are reported.
- Protected/default GitHub branches are excluded.
- No analytics or telemetry code is included.
- Page content is inspected locally; it is not sent to a BulkOperation server.

Do not include credentials, cookies, tokens, or private page data in bug reports.
